# Frontend

Frontend for the Real Estate Management project. See the [main README](../README.md) for team and course information.

## Stack

- **HTML** — semantic markup, using the tags covered in class.
- **CSS** — styling and layout.
- **JavaScript** — light interactivity only.

## Guidelines

- Build the pages with the HTML tags learned in class, keeping the markup simple and semantic.
- Apply responsiveness with **CSS media queries**, so the layout adapts correctly to mobile devices.
